## Why the validator missed WBC

`MedicalSafetyValidator` normalizes accents and checks a small regex/token list for diagnosis, medication/treatment, and cause speculation. The WBC sentence contains none of those configured phrases. There are no rules for `không có dấu hiệu`, infection/inflammation exclusion, stable immunity, normal organ function, `đảm bảo ... bình thường`, or `mức tối ưu`. `guardrail_node` sets `guardrail_passed` from whether that validator returns any violation, so the unsafe WBC inference produced a false `true` result.

## Minimal remediation boundary

1. Expand the analyzer prompt with explicit generic status/reference/critical/context contracts; no analyte-specific branch or hardcoded response.
2. Add narrow accent-insensitive inference patterns to `MedicalSafetyValidator` for the exact observed high-risk classes.
3. Strengthen the guardrail rewrite instruction so it removes the detected inference without adding new medical facts.
4. Add deterministic regression fixtures based on failures A–E plus disclaimer, critical-warning, and Fix2 preservation tests.

No Reference Range, Critical Detector, conversion, RAG index, API, frontend, database, or medical-data change is needed.
