### 5. OrchestratorSessionContext — SERVER-CONSTRUCTED ONLY
Fields:
  session_id, user_role, onboarding_acknowledged, current_report_ref,
  current_analyte, last_intent, pending_ocr_review, transient_ui_context

Rules:
- Never accepted from a client request. Constructed server-side only.
- pending_ocr_review is READ-ONLY / DERIVED from the OCR review gate
  (src/services/ocr_review_gate.py). Model it so a client value cannot set it.
- MUST NOT contain: chat transcript history, patient_id, user_id, auth tokens,
  DB primary keys, raw lab values, ocr_drafts.
- session_id is a server-side identifier. For guests it may derive from the JWT
  `sid` claim (confirmed stable for token lifetime, signed, non-persistent).
  Never put `uid` in it.
- Module docstring MUST state the three-way separation and that these are
  three distinct things that must never be merged:
    (a) LangGraph workflow checkpoint  -> src/agents/state.py AgentState
    (b) persistent medical DB          -> history_repository / SQLAlchemy
    (c) conversational session context -> this type

### 6. UIContext — client-supplied, UNTRUSTED
Carries screen/view hints, a candidate analyte, a candidate report_ref.
Docstring must state: this is a hint only. It never grants authority, never
changes role, never selects a report the user does not own.

### 7. SuggestedAction — discriminated union, EXACTLY 7 variants
OPEN_REPORT, VIEW_ABNORMAL, VIEW_HISTORY, VIEW_TREND,
VIEW_DOCTOR_QUESTIONS, CONFIRM_OCR, RETRY

Implementation:
- Discriminate on a Literal `action` field using
  Annotated[Union[...], Field(discriminator="action")].
- Every variant sets model_config = ConfigDict(extra="forbid").
- Each variant carries ONLY server-buildable, validated identifiers
  (e.g. OPEN_REPORT -> report_ref; VIEW_TREND -> analyte_id).

The type system MUST make these UNREPRESENTABLE in every variant:
  any url / href / route / link / path string field
  patient_id or user_id
  any free-form dict / Any / JSON payload field
  any field whose value could be navigated to or executed verbatim

SPECIAL CONSTRAINT — CONFIRM_OCR (Human Owner decision D-C, P0 safety invariant):
  The CONFIRM_OCR variant may carry ONLY a server-issued review reference
  (the signed review token identifier). It MUST NOT carry indicator values,
  draft rows, analyte values, units, or anything derived from ocr_drafts.
  OCR values reach the medical pipeline through exactly one door: /ocr/confirm
  after validate_review(). Making draft values representable in an action payload
  would open a laundering path at the type level. Do not open it.

### 8. Typed response payloads — discriminated on data_type
  AnalysisDataPayload     — wraps IndicatorResultSchema list + CriticalAlertSchema list
  ExplanationDataPayload  — explanation text + sources: list[str]
  HistorySummaryPayload   — shaped from history_repository.to_detail() projection
  TrendDataPayload        — wraps TrendResponse
  DoctorQuestionsPayload  — question list matching question_templates output
  BlockedPayload          — safety notice / disclaimer context
  NeedsInputPayload       — what is missing, what the user should specify

Reuse the existing schemas listed in PROJECT CONTEXT as inner types.
Do not re-declare indicator, critical alert, trend, or question field shapes by hand.

### 9. OrchestratorRequest / OrchestratorResponse

OrchestratorRequest:
  fields: message, ui_context (optional), client_request_id (optional)
  model_config = ConfigDict(extra="forbid")   <- REQUIRED. This is what makes AC7/AC8 pass.
  MUST NOT declare: patient_id, user_id, user_role, onboarding_acknowledged,
  pending_ocr_review, session context, intent, auth fields, ocr_drafts.

OrchestratorResponse:
  fields: intent, status, message, data_type, data, reason_code,
          suggested_actions, sources, safety_notice
  `data` is the §8 discriminated union via Field(discriminator="data_type").
  `data` MUST NOT be dict, Any, JsonValue, or a base model with extra="allow".
  `sources` is list[str] of URLs (Decision D-2).
