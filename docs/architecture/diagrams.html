Diagram 3 — LangGraph Medical Pipeline

StateGraph phân tích phiếu xét nghiệm

Deterministic rule check → critical detection → RAG/LLM explanation → guardrail an toàn y tế.

    ROUTE -->|Yes| GATE[ui_review_gate<br/>HITL Interrupt]
    GATE --> INTEGRITY[input_integrity<br/>Source-backed measurement<br/>plausibility rules]
    ROUTE -->|No| INTEGRITY
    INTEGRITY --> REF[reference_range_checker]

    CRIT --> ANALYZE[analyzer<br/>RAG + LLM]

    GEN_Q --> GUARD[guardrail<br/>Safety Validator]
    GUARD --> FINISH([End])

Diagram 4 — Orchestrator Agent

Canonical Conversational Agent

Admission gates → session context → tool selection có kiểm soát → guardrail phản hồi → suggested actions. Gates dưới đây đã đơn giản hoá cho overview — code thật (src/orchestrator/gates.py) có thêm emergency_safety_gate, sensitive_system_gate, out_of_scope_gate, treatment_followup_gate và các kiểm tra input mơ hồ. Đã bỏ gate "lab values trong chat" khỏi sơ đồ vì contains_lab_value() trong code không reject — nó chỉ miễn trừ tin nhắn khỏi bị chặn nhầm unclear/out-of-scope.
